    HOW TO READ THIS COMPARISON

    Measured results. Visible assumptions.

    One test set

    Accuracy is the fraction of correct sentiment labels across the complete matching test set. Partial runs and runs with failed examples are excluded from the plots, so the comparison keeps the same denominator.

    Two kinds of cost

    LLM and decision cost sums the retained prediction attempts. Earlier failed attempts stay in API logs and may have unknown charges. DL cost estimates use measured runtime and your chosen hourly compute rate. The timing basis and provider rate are explicit controls.

    Original files

    The explorer reads saved files in results/. It does not send prompts or make model API requests. The sources below identify the inputs and pricing references. Grouping keeps each configuration separate and never averages or combines scores.
