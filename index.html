    Methods, pricing and source files

    Scores from predictions

    Predictions are joined to the answer key by ID and checked against the sentence text. Accuracy counts missing or invalid answers as incorrect. Macro F1 averages negative, neutral and positive F1; balanced accuracy averages recall for classes present in the answer key.

    Default plots require exactly one valid prediction for every sentence. Partial runs remain in the results table. DL confidence is a classification probability; the LLM files do not contain comparable confidence values. A full-set confidence mean requires a valid saved confidence for every sentence.

    What “overall” means

    Overall averages the selected available reasoning configurations within each LLM. Cost and timing are means for one same-size run, not the sum of three runs. It is not an ensemble, and repeated sentences are not new independent samples. DL keeps its single GPU configuration.

    Cost & timing

    Recorded API charges take precedence. When absent, reference estimates assume all input tokens are uncached and output = total tokens − input tokens, including thinking. If totals are unavailable, saved completion tokens are used. Missing prices or usage remain unknown, not zero. Estimates do not include unreported retry usage or proxy fees. Zero and negative values cannot be placed on a log axis.

    DL measures synchronized GPU inference, excluding loading and warmup. API latency includes network/proxy overhead and any recorded retries. Hardware and execution environments differ.
